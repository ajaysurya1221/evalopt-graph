# Astra independent proposal: routing and integration boundary

There is no wedge integration. The documentation routes users to existing capabilities while leaving domain semantics and enforcement with their owners. No new evalopt dependency, bridge, predicate, adapter, signature format or common runtime is created in this sprint.

Route general policy evaluation to OPA; software provenance and attestation verification to in-toto and Witness; merge enforcement to GitHub rulesets and required checks. Route action-policy qualification to Actseal, code-claim warrants to Dorian, PR scope to Frontier Scout and stochastic regression to ARCI. These are job-oriented pointers, not tested drop-in replacements. Cite primary documentation for external standards; describe the four projects from their actual current source and README contracts. Retired SLSA VSA illustrates historical policy-verification summaries without being recommended for new deployments.

Explicitly separate policy evaluation, evidence integrity, producer authentication, semantic claim support and operational enforcement. Preserve the host's obligation to protect policy and authorized records, establish identity, retrieve material, manage isolation and choose the action following a decision. A content hash binds bytes; a trusted signature can bind a statement to an identity within a verification system; neither proves an arbitrary claim true. Portable records require their original version and limits to remain intelligible.

The portfolio audit records manifests, locks and runtime imports separately from documentation links and adapted-source licensing provenance. Zero package coupling never justifies deleting attribution. README changes in sibling repositories remain narrow PRs, unmerged by this run. All old benchmark studies and branch histories stay preserved and are linked through immutable public locations where useful; no result is merged or corrected as part of closure.

Any request for a new integration belongs outside this run. Reopening requires all memo conditions together: three independent organisations requesting the same missing capability, a demonstrated gap not reasonably covered by composing established tools, one committed production-grade integration/conformance deployment, and clearing the 80-percent-overlap gate. No such demand is assumed or pursued during wind-down.
