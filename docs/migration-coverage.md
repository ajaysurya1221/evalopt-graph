# Migration map: coverage record

Inventory of the sixteen entries in [migration.md](migration.md), each with its primary label, the
baseline lines it was checked against at commit `fc3045dbda29c1d274747329ceb6724a783b0df7` and the
external sources consulted (keys in [migration-sources.md](migration-sources.md)). This record is an
inventory of checked mappings. It is not interoperability certification, not standards conformance
and not a statement about the outcome of the independent reviews the wind-down run requires; those
outcomes are recorded by the run, not here.

Roster: the ten stable exports in `__all__` order (`__init__.py:21–32`) plus six cross-cutting
topics fixed by [migration-interface.md](decisions/migration-interface.md). Label counts: conceptual
analogy 5, host responsibility 4, project-specific semantics 4, no supported equivalence 3.

Method: each row's cited lines were read from the baseline commit with `git show`, and each cited
external anchor was read from the snapshot revision listed in the appendix. No test suite, converter,
schema, model call or live evaluation was involved; the coverage check is reading, not execution.
