V2 separates semantic outcomes, command execution, evidence availability,
container termination, native lifecycle and resource completeness. Its registered
primary contrast is the full skill versus the same skill with only the conditional
evidence/dispute procedure removed. Harness repairs are common to every arm.
The development result does not establish the effect of that procedure.

The revised round has 40 complete and 8 partial usage records; incomplete totals
are retained as lower bounds. Original-round unknown outcomes remain unknown.
Public reproduction checks retained-data consistency, not independent model
replication. Authoring and review were separated AI roles in a maintainer-run
study. V1 remains unchanged; external transfer is deferred and unexecuted held-out
task assets remain private.
